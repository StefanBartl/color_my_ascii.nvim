# Feature extensions for color_my_ascii.nvim 0.3.0

## Misc

1. **commands**
    - Move the commands into the correct module
    - Implement new usercommands
2. **Treesitter**
    - Clarify what it would buy us
    - Clarify how it would be implemented

## Performance

1. **Lazy loading for large files**
   - Above N lines/blocks, highlight only the visible ranges
   - Virtual scrolling with on-demand highlighting

2. **Caching of parsing results**
   - A cache for already parsed blocks (a weak table)
   - Invalidation only on text changes within the block

3. **Optimise the debounced updates**
   - Adaptive debounce time based on the file size
   - Separate timers per buffer

4. **Parallel processing**
   - Multi-block parsing via vim.loop
   - Asynchronous highlighting for large documents

## Security

1. **Input sanitisation**
   - Validation of all user inputs
   - Escaping of pattern metacharacters

2. **Error recovery**
   - Graceful degradation on parsing errors
   - Fallback to minimal highlighting
   - User notifications on critical errors

## Functionality

1. **Custom language definitions**
   - The user can add their own languages via the config
   - Hot reload of language files

1. **Integration features**
   - Telescope integration (an ASCII block picker)
   - LSP integration (semantic highlighting)
